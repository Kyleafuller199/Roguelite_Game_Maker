# Roguelite Game Maker

**Senior Software Engineering Project – CS 461, Oregon State University**

## Overview

Roguelite Game Maker is a web-based creation tool that lets you design, configure, and play-test roguelite-style games without writing code. It consists of two parts that work together:

- **Frontend Editor** – a React app for creating assets and composing projects
- **Map Viewer** – a pygame runner that loads your project and lets you play through it

The workflow is: **Create assets → Configure project → Start Run → Play in viewer**

## How to Run

### Frontend Editor
```bash
cd frontend/frontend_app
npm install
npm start
```
Opens at `http://localhost:3000`

### Map Viewer
```bash
cd roguelite_map_generator
python main.py
```
Reads `roguelite_map_generator/run_config.json` on startup.

> **Connecting them:** Click **Start Run** in the editor to generate `run_config.json`, then launch the map viewer to play your project.

## Editor Guide

The editor has two modes, toggled at the top:

### Asset Mode
Create and edit the building blocks of your game:
- **Cards** – name, type, rarity, cost, effects, scaling rules
- **Relics** – passive items with trigger-based effects
- **Potions** – consumables with a use context (any time / combat only / out of combat)
- **Enemies** – health, block, move sets, and AI behavior (cycle or custom)

Rarity options: `Starter | Common | Uncommon | Rare | Curse` (cards), `Starter | Common | Uncommon | Rare | Boss | Shop` (relics/potions)

### Project Mode
Compose your game from the assets you've created:
- **Project** – top-level container; owns the potion pool, enemy pool, and acts
- **Acts** – assign enemies to act 1/2/3 by role (basic, elite, boss)
- **Characters** – set a starting relic, starting deck, and per-character card/relic reward pools

> Starter-rarity cards and relics go in a character's starting deck / starting relic slot. Non-starter items go in the reward pools.

## run_config.json

This file is the bridge between the editor and the map viewer. The editor's **Start Run** button builds it from your project state. It contains:

- Full asset maps (`cardMap`, `relicMap`, `potionMap`, `enemyMap`) keyed by ID
- Character info (`startingDeck`, `startingRelicId`)
- Act assignments (`acts.1.basics`, `acts.1.elites`, etc.)
- Reward pools (`cardPool`, `relicPool`, `potionPool`)

See `JSON_STRUCTURE.txt` for the complete schema.

---

## Map Viewer

The pygame viewer reads `run_config.json` and runs an interactive session:

- Displays a procedurally generated node map
- Click a node to enter it (battle, elite, boss, rest, treasure, event)
- In battle nodes: your deck is built from the character's starting deck, enemies are drawn from the act's enemy list
- Cards are shown in hand and can be played by clicking
